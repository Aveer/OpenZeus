# skills/ — OpenZeus capability map

OpenZeus intentionally ships a small OpenCode-specific skill set.

| Skill | Responsibility |
|---|---|
| `zeus-diagnostics` | Runtime/config discovery, provenance, precedence and troubleshooting |
| `zeus-migration` | Safe OpenCode config/asset migration planning |
| `zeus-agents` | Advanced agent design and review |
| `zeus-commands` | Slash-command design and review |
| `zeus-skills` | Skill authoring, discovery and portability |

Generic technical knowledge, pseudo-introspection, meta-skill proliferation and
copied documentation for unrelated plugins are outside core.

For exact OpenCode syntax, use the current schema and official docs.
